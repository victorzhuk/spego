# add-tern-plugin-support

Ship a static, host-only Stencil Tern plugin that renders spego's delivery board and per-change details natively, backed by `spego board --fresh` and additive per-change task counts in board JSON.

- New capability: `tern-delivery-board`.
- Modified capability: `delivery-mirror`.
- Planned package location: `plugins/tern-spego/`.
- Status: planning complete, implementation not started.
